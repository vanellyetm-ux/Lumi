# Music Production — The Łand Ơf Mů

The public-facing Lumi music stream is connected to a separate private production and rendering environment.

- **Production repository:** https://github.com/Vanellye/the-land-of-mu
- **Main stream frame:** https://github.com/Vanellye/the-land-of-mu/blob/main/MAIN-STREAM.md
- **Composition/data library:** https://github.com/Vanellye/DataEnvelopeMint
- **Provenance bridge:** https://github.com/vanellyetm-ux/-ilk--mirror/blob/main/music/LAND-OF-MU-RENDER-RELEASE-BRIDGE.md

The Land of Mu includes a starter WAV/MIDI renderer and an automated render smoke-test workflow. The renderer creates actual PCM WAV and Standard MIDI files from machine-readable arrangements. Its current sound generation is a basic sine oscillator, not a finished commercial instrument or mastering engine.

Lumi is an index only. It does not expose private production files or imply that an asset has been approved for public distribution.

Public release requires rights review, technical and listening checks, final metadata/artwork, human approval, and post-publication verification. Only approved release URLs should be added to this public stream.
