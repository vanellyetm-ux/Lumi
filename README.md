# Lumi — VaN Knowledge HQ

Lumi is the narrative-facing entry point for VaN Knowledge HQ, connecting the $ilk mirror, GHOST–OLPIRT bridge, and independently reviewable knowledge destinations.

## Narrative flow
**Origin / OLPIRT → BOF / Foundation → GHOST / Translation → $ilk Mirror / Provenance → Ash / Knowledge foundation → VaN HQ / Stewardship → AshShow/V / Optional external presentation**

Each stage preserves authorship, context, confidence, and source lineage. Observations, interpretations, proposals, and open questions remain distinct.

## Promotion ladder
`DRAFT → SOURCE_VERIFIED → EVIDENCE_REVIEWED → IMPLEMENTATION_VERIFIED → PROMOTION_APPROVED → PUBLISHED`

Publication requires a human-approved destination scope and verified destination readback. Ash and any external AshShow/V presentation have separate permissions, approvals, and receipts.
